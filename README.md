# CarbonTrack Space

Sistema web para monitoramento ambiental utilizando dados orbitais simulados.

## Sobre o Projeto

O CarbonTrack Space é uma plataforma desenvolvida para auxiliar organizações, ONGs, fazendas e instituições governamentais no monitoramento de áreas ambientais.

A solução permite acompanhar áreas monitoradas, visualizar indicadores ambientais, analisar alertas e gerar relatórios para apoio à tomada de decisão.

Este projeto foi desenvolvido para fins acadêmicos como parte da Global Solution FIAP.

---

## Funcionalidades

- Login de organizações
- Cadastro de organizações
- Dashboard ambiental
- Visualização de áreas monitoradas
- Cadastro de novas áreas
- Alertas ambientais
- Relatórios ambientais
- Download de PDF
- Dados orbitais simulados

```bash

```

## Observações

- Este projeto utiliza dados simulados para fins acadêmicos.
- As análises ambientais apresentadas possuem caráter demonstrativo.
- O sistema não utiliza dados ambientais reais.
